# Security

Please don't open a public issue for a security problem. Email the maintainer at the contact address on [booknod.ca/privacy](https://booknod.ca/privacy) with the details, and we'll reply as soon as we can.

Never commit keys or secrets. All secrets belong in your Cloudflare dashboard (Settings → Variables and Secrets) or in a local `.dev.vars` file, which is ignored by git.
